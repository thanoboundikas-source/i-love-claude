# Solstice

A Mac-first Minecraft shader pack for Iris (Minecraft 26.1.2), written from
scratch for OpenGL 4.1, the macOS ceiling, as the *only* target. No compute
shaders, SSBOs, image load/store or geometry shaders anywhere.

**Look:** bright, saturated, clean, vanilla-faithful (Complementary Reimagined
mood) with Bliss/Photon-level lighting quality.

## Status

- [x] Overworld: procedural sky, blocky volumetric clouds from vanilla shapes,
      soft shadow-mapped lighting, coloured block light, water with
      reflections/refraction, sky-matched fog, godrays, rain wet look, TAA,
      bloom, sharpening, generated normals/specular, three profiles.
- [x] Nether / End: safe forward fallback (vanilla lightmap + Solstice grade).
- [ ] Full Nether and End looks (later).

Start with **[REPORT.md](REPORT.md)** (what was built, what to test first),
then **[TESTING.md](TESTING.md)** (comparison session against Reimagined).

## Install

The repo *is* the pack. It lives in the Lunar profile's shader folder:
`~/.lunarclient/profiles/fullbright-4/shaderpacks/Solstice`. In game press
**O** → select **Solstice** → **Apply**. **I** reloads shaders on this
profile, **K** toggles them.

## Layout

- `shaders/shaders.properties`: profiles, menu, pass switches, buffer sizes
- `shaders/block.properties`, `shaders/dimension.properties`
- `shaders/lang/en_us.lang`: option labels and tooltips
- `shaders/lib/`: shared code (`settings.glsl` holds every option)
- `shaders/program/`: program bodies; `shaders/*.vsh|fsh`,
  `shaders/nether/`, `shaders/end/` are thin stubs generated by
  `tools/gen_stubs.py`
- `tools/`: `check.sh` backend, Apple-GL compile harness, preview renderer,
  game-log and screenshot helpers
- `CLAUDE.md` (rules for future sessions), `DECISIONS.md` (design log)
